# LUMORA Trailer

Kleine Hilfsseite für die LUMORA-TV-App. Sie spielt einen YouTube-Trailer stumm ab und meldet der App per `postMessage`, wann er läuft.

YouTube-Player brauchen eine Webadresse. LUMORA läuft auf dem Fernseher als Datei, deshalb gehen die Trailer über diese Seite.

Aufruf: `https://creativelabs-de.github.io/lumora-trailer/#v=<YouTube-ID>&s=<Startsekunde>`

Die Seite enthält keine App, keine Daten und kein Tracking.
